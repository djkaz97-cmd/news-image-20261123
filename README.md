# The World Ledger — Monday, 23 November 2026

A 1024×1024 newspaper front page summing up Monday 23 November 2026:
36 dated stories across seven regions — one COP31 lead with a drawn summit
scene and 35 concise reports (five each for the Americas, Europe, Africa,
Middle East, South Asia, East Asia and Oceania), plus a market/sport tape.
Headlines were checked against reports dated 23 November from Reuters, AP,
BBC, RNZ, Africanews, AllAfrica, Dawn, Arab News and other outlets.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program validates the shipped PNG and writes its exact bytes to
`$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`). It uses no network,
clock or external packages, so repeated runs produce identical files.
