# The World Ledger — Monday, 23 November 2026

A 1024×1024 newspaper front page that sums up the world's news of Monday
23 November 2026: one lead story, two second leads and a 36-item grid —
39 dated stories across seven regions (Americas, Europe, Africa, Middle East,
South Asia, East Asia, Oceania), plus a market and sport tape.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies `entry.png` — the page drawn at build time — to
`$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`). No network, no clock,
standard library only.
